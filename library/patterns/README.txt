PATTERNS
========

EN  Put pattern tiles here (PNG, JPG, WebP, SVG, GIF). Single-colour or transparent images can be tinted with
    "Pattern colour"; coloured images are used as they are. Size, offset, rotation, mirror and opacity are set per
    pattern layer. Press "Reload" after adding files.

ID  Taruh tile pola di folder ini (PNG, JPG, WebP, SVG, GIF). Gambar satu warna / transparan bisa diwarnai dengan
    "Warna Pola"; gambar berwarna dipakai apa adanya. Ukuran, geser, rotasi, cermin, dan opasitas diatur per layer
    pola. Klik "Muat ulang" setelah menambah file.
