FONTS
=====

EN  Put font files (.ttf, .otf, .woff, .woff2) here. The file name (without extension) becomes the font name in the
    editor, e.g. "Bebas Neue.ttf" shows up as "Bebas Neue".
    The font_pes folder is written by the Fontset Generator (Save to library): one folder per PES font, picked in
    the Name tab.

ID  Taruh file font (.ttf, .otf, .woff, .woff2) di folder ini. Nama file (tanpa ekstensi) menjadi nama font di
    editor, mis. "Bebas Neue.ttf" muncul sebagai "Bebas Neue".
    Folder font_pes diisi oleh Fontset Generator (Simpan ke library): satu folder per font PES, dipilih di tab Nama.
