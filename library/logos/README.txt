LOGOS
=====

EN  Put logos here (PNG, JPG, WebP, SVG, GIF). Sub-folders are categories, for example brand/, sponsor/, club/.
    They appear in the Logo tab under "My Logos", with a category filter. Press "Reload" after adding files.
    The app ships WITHOUT any logos: add your own. Do not commit them to Git (they are trademarks).

ID  Taruh logo di folder ini (PNG, JPG, WebP, SVG, GIF). Sub-folder dipakai sebagai kategori, mis. brand/, sponsor/,
    klub/. Logo muncul di tab Logo > "Logo Saya" dengan filter kategori. Klik "Muat ulang" setelah menambah file.
    Aplikasi dibagikan TANPA logo: tambahkan sendiri. Jangan di-commit ke Git (merek dagang).
